Do you remember the old google, with the normal definitions and no ai overview? While Ai overview can be usefull, this extension loads the page with the condition of udm=14, which loads a special version of google, that google itself made that has no ai overview. You can still acces gemeni, by clicking the ai tab. 

How you can use it. First, install it!
Secondly, search normally and see a older version of google come back to life.
To search up the definition of a word, for example hello, search "def hello" or "definition hello". The quotation marks aren't required. If you search up definition of hello, it will show the definition of "of", which isn't what you most probably want. Right now, I just take the word after def and search that and give you the results, however later I plan to make it a bit more complex. Please spell definition correctly, or just use def. Additionally, please make sure you spell the word you want to find the definition of correctly. If you spell it wrong and then click on the "did you mean", it won't work. Also now you actively recall how to spell words. Hoorah!
